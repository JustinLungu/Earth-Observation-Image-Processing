# Earth-Observation-Image-Processing
Image processing and remote sensing exercises using satellite imagery, spectral and spatial features, and machine learning (EPFL ENV-540: Image Processing for Earth Observation).


Entropy measures how disordered or varied the pixel values are in a region, with higher entropy meaning a more complex or less uniform texture. (how mixed the pixel values are: a smooth area has low entropy, while a highly textured or varied area has high entropy.)
